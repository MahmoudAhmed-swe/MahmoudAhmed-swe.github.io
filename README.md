# Mahmoud Ahmed — Portfolio

Static GitHub Pages portfolio split into:

- `index.html` — content and structure
- `styles.css` — responsive visual design
- `script.js` — theme, mobile navigation, scroll reveal and active section state
- `assets/profile.jpg` — your profile photo (add it yourself)
- `assets/Mahmoud-Ahmed-CV.pdf` — your CV (add it yourself)

## Before publishing
Replace the placeholders in `index.html`:
- LinkedIn URL
- WhatsApp number
- Email address
- Facebook URL

The design intentionally avoids heavy continuous animations and external UI libraries so it remains fast on mobile.
